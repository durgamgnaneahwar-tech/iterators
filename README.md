
# Bank Management System

## Project Overview
The Bank Management System is a Python and MySQL-based application used to manage customer bank accounts and financial transactions.

## Technologies Used
- Python
- MySQL
- MySQL Connector
- Object-Oriented Programming
- SQL

## Features
1. Create Bank Account
2. Check Account Balance
3. Deposit Money
4. Withdraw Money
5. Credit Simple Interest
6. View Transaction History

## Database Tables

### Accounts
- account_number
- customer_name
- balance

### Transactions
- transaction_id
- account_number
- transaction_type
- amount
- transaction_date
- balance_after

## Installation

Install the required package:

pip install -r requirements.txt

## Database Setup

1. Open MySQL Workbench.
2. Execute bank_management_system.sql.
3. Verify the database and tables.

## Run Project

python bank_management.py
